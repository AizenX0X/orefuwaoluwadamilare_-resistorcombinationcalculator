# orefuwaoluwadamilare_-resistorcombinationcalculator
The Resistor Combination Calculator is a simple and reliable tool designed to help users calculate the total resistance of resistors connected in Series and Parallel combinations.
CTE213 Resistor Calculator

Project Description

The CTE213 Resistor Calculator is a Python-based program designed to calculate the resistance value of a resistor using its colour bands.

The program identifies resistor colour codes and calculates the resistance value in ohms (Ω), including decimal values where applicable.

Features

- Calculates resistor resistance using colour codes.
- Supports standard resistor colour bands.
- Displays resistance in ohms (Ω).
- Handles decimal resistance values.
- Provides a simple, user-friendly interface.

Technology Used

- Programming Language: Python 3
- Development Environment: Python IDE / Terminal

How to Run the Program

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

python resistor_calculator.py
